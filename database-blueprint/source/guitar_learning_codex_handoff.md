# Guitar Learning Roadmap + Resource Spreadsheet — Codex Handoff

## Purpose
Build or extend a comprehensive guitar-learning spreadsheet / app data model where each learning section contains:

- Learning phase
- Skill node
- Level
- Objective
- Key concepts
- Practice tasks
- Pass condition
- YouTube links
- Further resources
- Song/application ideas
- Status
- Priority
- Notes

This is intended for a guitar-learning app or workbook called **The Hearth Mastery**, with a dark, mystical, structured learning aesthetic.

---

## Core Learning Philosophy
Every skill should move through this loop:

**Learn → Hear → Play → Use in a Song → Create With It**

Avoid building a dry checklist. Each topic should connect to actual music, songs, improvisation, composition, or performance.

---

## Roadmap Stages

### 0. Initiation — “Hold the Instrument”
**Goal:** Make the guitar feel familiar.

Learn:
- Parts of the guitar
- Tuning
- Pick vs fingers
- How to hold the guitar
- Fretting clean notes
- Basic rhythm pulse

Pass condition:
- Can tune the guitar
- Can play single notes cleanly
- Can clap/count steady quarter notes

App metaphor: **The First Ember**

---

### 1. First Chords — “Make Songs Happen”
**Goal:** Play real songs quickly.

Learn:
- Open chords: Em, G, C, D, Am, E, A
- Chord changes
- Simple down-strum patterns
- 2-chord and 3-chord songs
- Basic song structure: verse, chorus, bridge

Pass condition:
- Can change between 4–6 open chords without stopping
- Can play 3 simple songs from start to finish

App metaphor: **The Hearth Is Lit**

---

### 2. Rhythm Foundation — “Become Playable”
**Goal:** Stop sounding like a beginner.

Learn:
- Down/up strumming
- Eighth-note rhythm
- Muted strums
- Accents
- Common patterns: folk, pop, rock
- Playing with a metronome

Pass condition:
- Can keep time through a full song
- Can change strumming feel without losing the beat

App metaphor: **The Pulse Chamber**

---

### 3. Fretboard Orientation — “Know Where You Are”
**Goal:** Understand the neck instead of memorising shapes blindly.

Learn:
- String names
- Natural notes on E and A strings
- Octave shapes
- Sharps/flats
- The 12-fret repeat
- Root-note awareness

Pass condition:
- Can find any natural note on the low E and A strings
- Can identify roots inside common chord shapes

App metaphor: **The Map of the Neck**

---

### 4. Technique Core — “Train the Hands”
**Goal:** Build clean, reliable movement.

Learn:
- Alternate picking
- Hammer-ons and pull-offs
- Slides
- Bends
- Vibrato
- Palm muting
- Basic fingerpicking
- Clean chord fretting

Pass condition:
- Can play simple riffs cleanly
- Can control volume, muting, and note length
- Can play without excess tension

App metaphor: **The Forge**

---

### 5. Barre Chords & Movable Shapes — “Unlock the Neck”
**Goal:** Move beyond open-position playing.

Learn:
- F major shape
- E-shape barre chords
- A-shape barre chords
- Power chords
- Major/minor movable chord families
- Chord embellishments: sus2, sus4, add9, 7ths

Pass condition:
- Can play basic barre chords cleanly
- Can move one chord shape to different roots
- Can play songs in multiple keys

App metaphor: **The Iron Gate**

---

### 6. Scales & Lead Guitar — “Speak in Melody”
**Goal:** Start improvising and writing melodic lines.

Learn:
- Minor pentatonic scale
- Major pentatonic scale
- Blues scale
- Major scale
- Simple phrasing
- Call and response
- Target notes
- Repetition and variation

Pass condition:
- Can improvise a simple solo over a backing track
- Can make phrases that sound intentional, not random

App metaphor: **The Spark Path**

---

### 7. Theory That Actually Helps — “See the Pattern”
**Goal:** Understand what you’re playing.

Learn:
- Whole steps and half steps
- Major scale formula
- Chord construction: 1–3–5
- Major/minor difference
- Diatonic chords
- Roman numerals
- Common progressions: I–V–vi–IV, ii–V–I, I–IV–V

Pass condition:
- Can explain why G–D–Em–C works
- Can transpose a simple progression
- Can build major and minor triads

App metaphor: **The Alchemist’s Grammar**

---

### 8. Ear Training — “Hear Before You Play”
**Goal:** Connect ear, hand, and imagination.

Learn:
- Match pitch
- Hear major vs minor
- Recognise intervals
- Recognise chord movement
- Sing simple melodies
- Transcribe riffs and chord progressions

Pass condition:
- Can work out simple melodies by ear
- Can identify basic chord qualities
- Can hear when a chord change is likely going up/down in function

App metaphor: **The Listening Flame**

---

### 9. Repertoire & Song Learning — “Become Musical”
**Goal:** Build a living songbook.

Learn:
- 10 easy songs
- 10 intermediate songs
- 3 songs by ear
- 3 songs in full arrangement
- Lyrics/chords/rhythm integration
- Performance memory

Pass condition:
- Can play 20 songs at different difficulty levels
- Can perform 3 without stopping
- Can simplify hard songs into playable versions

App metaphor: **The Songbook Vault**

---

### 10. Style Paths — “Choose Your Guild”
**Goal:** Branch into musical identity.

Style paths:

#### Acoustic / Singer-Songwriter
- Fingerpicking
- Capo use
- Travis picking
- Chord melody
- Dynamics

#### Rock
- Power chords
- Riffs
- Palm muting
- Pentatonic soloing
- Gain control

#### Blues
- 12-bar form
- Shuffle rhythm
- Blues scale
- Bends/vibrato
- Turnarounds

#### Jazz / Neo-Soul
- 7th chords
- Shell voicings
- Extensions
- ii–V–I
- Chord melody

#### Metal
- Tight muting
- Downpicking
- Alternate picking
- Riff stamina
- Modal sounds

#### Worship / Ambient
- Add9/sus chords
- Swells
- Delay/reverb
- Capo voicings
- Simple melodic fills

App metaphor: **The Guild Halls**

---

### 11. Improvisation — “Speak Freely”
**Goal:** Play unrehearsed but musically.

Learn:
- Solo over one chord
- Solo over chord changes
- Chord-tone targeting
- Motifs
- Space
- Dynamics
- Question/answer phrasing

Pass condition:
- Can improvise over a 12-bar blues
- Can target chord tones when chords change
- Can create a short solo with a beginning, middle, and end

App metaphor: **The Wild Flame**

---

### 12. Composition & Arrangement — “Create Your Own Music”
**Goal:** Move from player to musician.

Learn:
- Write chord progressions
- Write riffs
- Create intros/outros
- Arrange a song for solo guitar
- Layer rhythm and lead parts
- Record demos

Pass condition:
- Can write a complete original piece
- Can arrange a cover in your own style
- Can record a clean demo

App metaphor: **The Hearthsong**

---

### 13. Performance — “Bring It to Life”
**Goal:** Play for people.

Learn:
- Practice sets
- Recover from mistakes
- Stage confidence
- Tone setup
- Playing with others
- Basic band roles
- Recording yourself

Pass condition:
- Can perform 3 songs for someone
- Can play with a backing track or another musician
- Can keep going after a mistake

App metaphor: **The First Offering**

---

## Implementation Notes for Codex

### If building a spreadsheet programmatically
Recommended file formats:
- `.xlsx` for the final workbook
- Optional `.csv` exports for each table
- Optional `.json` for app import

Recommended features:
- Freeze header rows
- Add filters to each table
- Add dropdown validation for Status, Priority, Level, Skill Node, Resource Type
- Wrap text in text-heavy columns
- Make URL columns clickable
- Add a dashboard chart for completion by Skill Node
- Add conditional formatting:
  - Complete = green
  - In Progress = amber
  - Not Started = muted/grey
  - High priority = strong highlight

### If building app data
Suggested object model:

```ts
type SkillNode =
  | "Rhythm"
  | "Chords"
  | "Fretboard"
  | "Technique"
  | "Theory"
  | "Ear Training"
  | "Scales & Lead"
  | "Songs"
  | "Improvisation / Creation";

type MasteryLevel = "Ember" | "Flame" | "Forge" | "Ritual" | "Mastery";

type RoadmapStatus = "Not Started" | "In Progress" | "Review" | "Complete";

type RoadmapItem = {
  phase: number;
  title: string;
  appMetaphor: string;
  skillNode: SkillNode;
  level: MasteryLevel;
  learningObjective: string;
  keyConcepts: string[];
  practiceTasks: string[];
  passConditions: string[];
  youtubeLinks: string[];
  furtherResources: string[];
  songApplications: string[];
  status: RoadmapStatus;
  priority: "Low" | "Medium" | "High";
  notes?: string;
};
```

## Best Learning Order

The most effective progression:

1. Tune guitar
2. Learn 4–6 open chords
3. Play real songs immediately
4. Build rhythm and strumming
5. Learn fretboard basics
6. Add technique
7. Learn barre chords
8. Learn pentatonic scales
9. Learn useful theory
10. Train the ear
11. Branch into style
12. Improvise, compose, perform

Core principle:

**Songs first, theory later — but rhythm always underneath.**
