# Practice Node System Notes

## Primary Source

Troy Nelson, *Guitar Aerobics*.

Source notes:

`database-blueprint/source/source_notes_batch_001_guitar_aerobics.csv`

## Core Insight

Practice works better when it is:

- small
- daily
- rotating
- musical
- measurable
- connected to style

The Practice node should not be only a timer.

It should be a ritualized daily challenge system.

## Guitar Aerobics Model

The book uses:

- 52 weeks
- 365 exercises
- one lick per day
- seven rotating technique categories
- musical style contexts
- tempo support
- short practical tips

This is highly compatible with The Hearth.

## Hearth Adaptation

The Hearth should not copy the book's exercises directly.

Instead, adapt the system:

- daily practice prompt
- rotating focus category
- short physical instruction
- tempo target
- style context
- pass condition
- reflection

## Practice Session Flow

Recommended Practice node flow:

1. Intention
2. Body scan
3. Warm-up
4. Focus drill
5. Musical application
6. Reflection
7. Next action

This combines:

- Jamie Andreas style correct-practice philosophy
- Guitar Aerobics daily challenge structure
- Hearth nervous-system/reflection layer

## Hearth Voice

Practice should feel like entering a room where the body learns honestly.

The guide should ask:

- What are you training today?
- What is the smallest clean version?
- Where did tension appear?
- What changed after five minutes?
- What wants to be repeated tomorrow?

## Recommendation

Use Guitar Aerobics as a structural inspiration for the Practice node, but let The Hearth own the deeper ritual:

**intention -> body -> repetition -> music -> reflection**

## Accepted Practice Design Decisions

### Daily Practice Cards

The Practice node should eventually offer daily practice cards.

A practice card should include:

- today's focus
- short drill
- level
- discipline
- tempo or timing guidance
- body cue
- musical application
- pass condition
- reflection prompt
- source citation where applicable

This makes Practice feel like a living ritual rather than a blank timer.

### Guided Rotation With Choice

Use a hybrid model:

- the app suggests a rotating focus so learners do not avoid weak areas
- the learner can override the suggestion when they have a specific need

Recommended UI language:

- `Today's suggested practice`
- `Choose another focus`

### Beginner vs Advanced Guidance

Beginners should receive more guidance.

Advanced learners can become more self-directed.

The app should gradually shift from:

`follow this small clean step`

to:

`choose your focus, define the pass condition, reflect honestly`

### Body And Nervous-System Reflection

Every practice session should include a short body/reflection check.

Keep it small:

- Where did tension appear?
- What got easier?
- What did your body learn?
- What should repeat tomorrow?

This is one of the main ways The Hearth differs from a normal guitar app.

### Three-Layer Practice Model

Every strong practice session should connect:

1. **Daily Card** - a concrete action
2. **Body Awareness** - tension, breath, ease, attention
3. **Musical Meaning** - how the drill connects to sound, song, or expression
