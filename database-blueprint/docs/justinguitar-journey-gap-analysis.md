Access note:

## What JustinGuitar Does Well

JustinGuitar is strong as a public-facing journey benchmark.

Visible strengths:

- clear beginner gradient across Grade 1, Grade 2, Grade 3
- early song use
- chords and rhythm first
- consolidation modules
- explicit grade language
- separate skill/topic shelves
- beginner to intermediate bridge
- ear training separated as its own path
- transcribing is visible
- style pathways appear in intermediate/advanced stages
- left-handed practice support appears through Nitsuj modules

This is especially useful because it shows a battle-tested beginner shape:

1. basics
2. first chords
3. rhythm/chord changes
4. strumming
5. metronome
6. first theory
7. first scale
8. F chord
9. alternate picking
10. fingerstyle/songwriting/blues/power chords
11. consolidation

## The Biggest Gaps

### 1. Hearth / Learning Science Layer

Justin shows guitar progression. It does not visibly show:

- what is changing in the brain/body
- why practice works
- how attention changes learning
- how mastery develops over time
- what to do when the learner freezes, forgets, or loses confidence

The Hearth should own this.

Source support:

- Ericsson source notes
- Patel source notes
- Levitin source notes
- Jamie Andreas source notes

### 2. Embodied Technique And Tension Awareness

Justin has technique categories, but the screenshots do not show a deep body-aware layer.

The Hearth should add:

- body scan before playing
- tension check after playing
- rest/free stroke as sensation and sound
- posture as adaptable alignment
- pressure/release
- breath and nervous-system check-ins

This is a major differentiator.

### 3. Source-Traceable Knowledge

Justin is a teaching site. The Hearth is becoming a sourced learning system.

Gap to fill:

- visible book/source references
- source notes behind explanations
- source-backed glossary
- references to books, videos, and audio examples

The learner does not need academic clutter, but the knowledge base should be traceable.

### 4. Practice As A Temple

Justin has lessons about practice, but the screenshots do not show practice as a dedicated ritual system.

The Hearth should build:

- daily cards
- practice timer
- intention before practice
- reflection after practice
- what changed in body/sound/mind
- streaks without shame
- maintenance and review cycles

This maps strongly to Ericsson: performance, retention, feedback, deliberate practice.

### 5. Music As Language

Justin has theory, chords, scales, ear training, and songs. It does not visibly frame them as one language-learning system.

The Hearth should explicitly connect:

- sound categories = vocabulary
- intervals/scales/chords = grammar
- songs/improvisation = conversation
- composition/expression = poetry

This maps strongly to Patel.

### 6. Ear Training Continuity

Visible Justin ear training is:

- introduction
- reference
- Grade 1
- Grade 2
- Grade 3

Gap:

Ear training should not stop at beginner grades.

The Hearth should carry listening through all 8 levels:

- Level 1: high/low, same/different, open/fretted, bright/dull
- Level 2: intervals, chord quality, major/minor, pentatonic sound
- Level 3: triads, simple progressions, blues vocabulary
- Level 4: key centers, scale degrees, chord function
- Level 5: harmonic minor, secondary dominants, odd meter
- Level 6: modes, substitutions, superimposition
- Level 7: altered/diminished/melodic minor colors
- Level 8: transcribing, recognition, creative use

### 7. Reading Music / Study Path

Justin's visible page includes tab/manuscript, neck notes, diagrams, theory, and transcribing.

Gap:

There is not a clearly visible, progressive reading-music path.

The Hearth should use Study to build:

- notation
- rhythm reading
- fretboard note reading
- tab vs staff
- diagrams
- glossary
- visual-to-physical-to-sound mapping

Source support:

- Shearer Part 2
- Leavitt/Berklee
- Schonbrun theory

### 8. Create Is Present But Not Central

Justin has songwriting and production modules.

Gap:

Creative work does not appear to be a repeating part of the learning loop.

The Hearth's Create node can be stronger:

- obstructions
- constraints
- improvisation dares
- lyric/riff/rhythm/story collisions
- creative reflection
- emotional risk

Create should not be a side shelf only. It should be a recurring way to own skills.

### 9. Personal Learning Profile

Justin is broadly accessible, but the screenshots do not show a personal learning-profile system.

The Hearth should support:

- learner profile
- multiple explanations
- simpler step on struggle
- ambiguity reduction
- boredom protection
- purpose context for every exercise

This is core to Ayla's design spec.

### 10. Advanced Path Completion

Justin's visible Grade 8 and Grade 9 are coming soon.

This is an opportunity.

The Hearth Level 8 can become:

- integrated command
- synthesis
- transcribing
- expression
- composing
- performing
- advanced improvisation
- personal voice

Do not wait for another system to define this. The Hearth can own it.

## What To Borrow As Structure

Borrow:

- grade/level clarity
- beginner gradient
- early songs
- consolidation moments
- skill shelves
- transcribing visibility
- topic modules for optional exploration

Do not borrow:

- the exact curriculum text
- private/account content
- a pure course-list interface
- a content-first experience with no embodied/reflection layer

## Hearth Journey Recommendation

Use JustinGuitar as a progression benchmark, QJam as a technical roadmap source, and The Hearth sources as the teaching philosophy.

Recommended blend:

- Justin: beginner gradient and public external resources
- QJam: 8-level technical roadmap and YouTube support
- Andreas/Shearer: body-aware technique and beginner physical method
- Schonbrun/Leavitt: Study/theory/reading path
- Patel/Levitin/Ericsson: Hearth learning science and music-as-language frame
- Guitar Aerobics/Dummies: practical drills and practice-card design

## The Hearth Difference

The Hearth should not try to be JustinGuitar with a mystical skin.

The Hearth should be:

- a scene-first learning world
- source-backed
- body-aware
- reflective
- neurologically literate
- creative
- emotionally alive
- useful as a reusable simulator engine

JustinGuitar helps us see the road.

The Hearth decides what the journey means.
