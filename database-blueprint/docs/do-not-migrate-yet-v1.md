# Do Not Migrate Yet V1

## Purpose

This list protects Martin from accidentally spending backend time on prototype leftovers.

Not everything that exists should be migrated.

## Do Not Migrate First

- `fcp-prototype.html`
- `simulator-prototype.html`
- `.bak` backup pages
- old duplicate node icon variants
- exact inline CSS from `simulator.html`
- exact `scene-first.js` behavior
- localStorage UI state such as `flameNode`
- `travelledPaths` as a primary data model
- weak auto-generated quiz logic
- hardcoded drill-to-level placement as final truth
- old Play node as mandatory core node
- duplicate Knowing icon experiments
- high-res character-full images until asset strategy is clear

## Review Later

- landing/splash page
- admin panel
- boot sequence
- exact old learning profile questionnaire UI
- world map / Play content
- toolkit icons not yet copied into blueprint
- Marty Music PDF
- Guitar Tricks resource set
- campfire ambience

## Migrate Carefully

- Journey multi-student data
- learning profile concept and learner preference tags
- practice logs
- create projects
- source notes
- book metadata
- PDF URLs
- TeachingEngine lesson steps
- Doing drills
- Knowledge topics

## Rule

If a file is visually charming but not structurally important, it can wait.

If a file contains learner progress, source knowledge, curriculum structure, or reusable engine logic, it deserves priority.
