# Journey Level One Lesson Vision - 2026-07-07

Plain English: this note preserves Ayla's raw Journey/Level 1 lesson design thought, then turns it into a structured working blueprint. It should guide the next Journey UI and lesson-flow work.

## Raw User Note

The "Let's begin" button does not have to be bottom right. It should fit the layout.

The Level 1 screen should not jump straight into the first lesson. When I click Level One, it makes sense to see some kind of roadmap, more like a curriculum.

The guide is there. He tells us not to get ahead of ourselves, stay calm, stay disciplined, and have fun, or something like that.

The map tells me what I am going to learn in this level. Maybe we could break it down like QJams does: rhythm, scales, etc.

The Level 1 map could be an actual map-style image, but I am not sure how exactly it should look yet. I imagine it like a hand-drawn map: this way, then this way, turn right at the thing. Maybe it is a mind map. The goal is that it shows the level goals as one defined image.

Then I see a button that says "Let's begin." It should fit the layout, not necessarily bottom right. Then I get Lesson 1.

Inside the lesson interface, I am presented with different icons in a line to indicate different categories or phases of that lesson. These phases may pull from each of the nodes.

The first phase says Tune In. We tune the guitar, so the tuner tool opens. We also tune in to our being. Then we get a candle tool like the Practice node, but it is just a body check. Maybe we make it guided. I can record something myself, or we can get a few different offline options, and it can change each time.

Then Warm Up the hands: stretches and physical preparation.

Then Warm Up the brain. We get a reminder of what we learned last time and what we are working with now. If we want, we can choose to open a book and read a section of information about it. For example, if we are learning the pentatonic scale: how does that fit in with everything else, and why are we learning it? Maybe there is a short video, but long videos should be for the Study node. I should have the option to study in that moment, because I can do warmup exercises on guitar while I watch a video about a concept.

Then "Get Into It": warmup scales and finger stretches.

After that I am ready to try something new. I get Learn, or "Stretch Your Brain." This should reflect in the Hearth node, in the brain section, where I learn about how my brain is stretching. Perhaps at some point we can define specific activities by how they stretch the brain. Note that.

Something new is taught.

Then I get Try It Out.

Then Practice. I do a certain number of minutes practicing in the Practice Temple with the candle. If I click Practice later, that practice should be there if I just want to do that.

I can record myself practicing each time and listen to how I improve. Record should be a tool.

Then Play. Apply the thing I just learned to something that makes me feel like I can play.

Then I get a groove. This is important for the Play node. It should be groove focused. Different traditions from around the world have different accents and cultures around rhythm and groove, and sometimes guitar-specific ways of playing. We learn something and play it to a metronome or groove backing track.

The thing I wrote today about applying the pentatonic scale with the three boxes is also a Play thing.

Then the last creative phase is Create and Experiment. That is where the Create node assists. We take this new tool, like the A minor pentatonic scale, where we learned the boxes and played to a groove, and then we have the option to prompt something new in: a lyrics prompt, a rhythm prompt, a groove prompt, or a call-and-response setup where one person solos and another holds down rhythm.

The final step of the lesson, while we stretch down, is watching a master in action. That develops the Mastery node. We see someone who has mastered the pentatonic scale, or someone who has gone beyond it in an interesting way, to remind us that you do not have to learn the thing everyone else learns. You can make your own thing up.

We still have a lot of work to do on the Mastery node.

A lesson should be an hour. Design it for an hour.

It is important to note that the nodes all talk to each other. They are nice places to go outside formal lessons too. I do not always want to do a whole lesson. The same goes for the Know and Study nodes.

The lessons draw from these nodes. For example, if I practice and note feedback, that feedback should be there when I practice inside the lessons.

## Structured Interpretation

### Journey's Role

Journey is the formal path.

The nodes are the living places/tools the path draws from.

Journey should not duplicate the nodes. Journey should send the learner into node-like activities at the right time, and any notes/progress made during a Journey lesson should also be visible when visiting that node directly.

### Level 1 Opening Screen

The Level 1 first click should show a curriculum roadmap before Lesson 1 starts.

It should answer:

- What am I going to learn in Level 1?
- Why does this level matter?
- What are the main skill areas?
- What is the first step?

Possible visual metaphors:

- Hand-drawn quest map.
- Curriculum path.
- Mind map.
- Guitar-learning route map.
- QJams-style breakdown by skill family: rhythm, chords, scales, improvisation, groove, etc.

The "Let's begin" button should fit the visual layout. It does not need to be bottom right.

### Guide Voice

The guide should be present and practical.

Possible tone:

- "Do not get ahead of yourself."
- "Stay calm."
- "Stay disciplined."
- "Have fun."
- "This level is built one small step at a time."

The guide should make the roadmap feel encouraging, not like a dashboard.

### One-Hour Lesson Flow

Working lesson sequence:

1. Tune In
2. Warm Up Hands
3. Warm Up Brain
4. Get Into It
5. Learn / Stretch Your Brain
6. Try It Out
7. Practice
8. Play / Groove
9. Create and Experiment
10. Watch a Master / Stretch Down / Reflect

This is a richer version of the earlier 6-block Journey flow. It may still compress into fewer UI sections, but the experience should include these functions.

### Node Connections

Tune In:

- Opens tuner tool.
- Adds body/being check.
- Uses candle-style focus from Practice, but as a body check rather than a full practice timer.
- May use offline guided audio options or recorded guide prompts.

Warm Up Hands:

- Stretches.
- Finger preparation.
- Physical readiness.

Warm Up Brain:

- Recap last lesson.
- Explain today's concept.
- Offer optional book section.
- Offer short directly relevant video.
- Long videos belong in Study.

Get Into It:

- Warmup scales.
- Finger stretches.
- Simple entry exercises.

Learn / Stretch Your Brain:

- Teach one new thing.
- Connect to Hearth brain learning.
- Later: tag activities by what they develop in the brain.

Try It Out:

- First low-pressure attempt.
- Small, safe gradient.

Practice:

- Uses Practice Temple/candle.
- Uses a timed practice block.
- Saves notes/feedback back to Practice.
- Recording should be a reusable tool.

Play / Groove:

- Apply the new thing musically.
- Use metronome or groove backing track.
- Develop Play node as groove-focused.
- Include global rhythmic traditions, accents, cultures, and guitar-specific groove styles.
- Pentatonic three-box/root-note safety-net work belongs here too.

Create and Experiment:

- Uses Create node.
- Prompts: lyrics, rhythm, groove, riff, call and response, one person solos while another holds rhythm.
- Turns the skill into a creative seed.

Watch a Master / Stretch Down:

- Develops Mastery node.
- Show a musician using the concept.
- Include examples of people going beyond the rule, so mastery means freedom, not imitation.

### Brain/Hearth Note

Activities should eventually be tagged by what they develop:

- Pattern recognition.
- Motor mapping.
- Timing.
- Listening.
- Memory.
- Prediction.
- Coordination.
- Creative choice.
- Feedback tolerance.
- Emotional regulation.

This belongs in the Hearth brain/body system.

### Progress Memory

If the user practices inside Journey, that practice note should also appear in Practice.

If the user studies inside Journey, that study activity should connect to Study/Knowing.

If the user creates inside Journey, that seed should connect to Create.

If the user watches a master inside Journey, that should connect to Mastery.

Journey should be the itinerary. The nodes should be reusable places.

## Credit-Efficient Build Recommendation

Do not generate a roadmap image yet.

First build a flexible HTML/CSS roadmap prototype using existing assets and code-native layout. This is cheaper, faster, and easier to revise.

Once the structure feels right, generate or hand-design a final map-style image only if the layout has stabilized.
