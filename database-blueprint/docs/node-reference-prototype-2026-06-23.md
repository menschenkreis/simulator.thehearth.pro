## 2. DOING NODE — Fretboard Grid

### What it is
The Doing node is a **CSS grid** (not SVG) that looks like a guitar fretboard.
6 strings × 8 levels = a grid of drill cards laid out like fret positions.

### How it's built (showDoing() in simulator.html ~line 2130)
The entire fretboard is generated by JavaScript into `#p-foundation` (shared panel).

### Layout structure:
```
<div class="doing-fretboard-stage">
  <div class="doing-string-labels">     ← 6 string note names (e, B, G, D, A, E)
    <div class="doing-string-note">e</div>
    ...
  </div>
  <div class="doing-fretboard-wrap">    ← scrollable fretboard
    <div class="doing-fretboard">
      <div class="doing-fret-header">   ← 8 level headers (I-VIII)
        <div class="doing-level-head">
          <span class="doing-level-roman">I</span>
          <span class="doing-level-name">Touch</span>
        </div>
        ...
      </div>
      <div class="doing-string-row">    ← one per string
        <div class="doing-fret-cell">   ← drill card per level×string
          <div class="doing-drill-card">
            <div class="drill-id">alt-1</div>
            <div class="drill-title">Alternate Picking 1</div>
            <div class="drill-meta">d:1 bpm:60 30s</div>
            <div class="drill-state">Mastered ✓</div>
          </div>
        </div>
        ...
      </div>
    </div>
  </div>
</div>
```

### CSS classes (simulator.html lines 406-440):
- `.doing-fretboard-stage` — grid container (34px labels + flex fretboard)
- `.doing-string-labels` — left column of string names
- `.doing-string-note` — each string letter (gold, Cinzel font)
- `.doing-fretboard-wrap` — scrollable container with wood-grain gradient background
- `.doing-fretboard` — min-width:920px, relative positioned
- `.doing-fret-header` — 8-column grid, level headers
- `.doing-level-head` — each level header (Roman numeral + name)
- `.doing-string-row` — 8-column grid per string, with horizontal "string" line via ::before
- `.doing-fret-cell` — individual drill slot
- `.doing-drill-card` — the drill card inside each cell
- `.style-filter` / `.doing-level-filter` — filter buttons above the fretboard

### String mapping (6 strings, each mapped to drill categories):
```javascript
const stringRows = [
  { id:'high-e', label:'e',  hint:'Speed / style',     weight:'1.4px', categories:['speed','styles'] },
  { id:'b',      label:'B',  hint:'Arpeggios / harmony', weight:'1.8px', categories:['arpeggios'] },
  { id:'g',      label:'G',  hint:'Scales / maps',     weight:'2.2px', categories:['scales'] },
  { id:'d',      label:'D',  hint:'Picking / attack',  weight:'2.6px', categories:['picking'] },
  { id:'a',      label:'A',  hint:'Fretting / grip',   weight:'3px',   categories:['fretting'] },
  { id:'low-e',  label:'E',  hint:'Rhythm / pulse',    weight:'3.4px', categories:['rhythm'] }
];
```

### Level mapping (8 levels with names):
```javascript
const levels = [
  { level:1, label:'Level I',   name:'Touch',     tag:'Clean first contact' },
  { level:2, label:'Level II',  name:'Control',   tag:'Two hands agree' },
  { level:3, label:'Level III', name:'Movement',  tag:'Crossings and changes' },
  { level:4, label:'Level IV',  name:'Groove',    tag:'Pulse becomes body' },
  { level:5, label:'Level V',   name:'Reach',     tag:'Neck opens wider' },
  { level:6, label:'Level VI',  name:'Flow',      tag:'Patterns connect' },
  { level:7, label:'Level VII', name:'Fire',      tag:'Advanced mechanics' },
  { level:8, label:'Level VIII',name:'Voice',     tag:'Technique becomes sound' }
];
```

### Drill data source:
- `window.DOING` object (loaded from `assets/js/doing.js`)
- `DOING.categories` — each has `.id` and `.drills[]` array
- Each drill has: `id, title, difficulty, bpm, duration, source, style, body` (HTML)
- Drill-to-level mapping is in `drillLevels` object (hardcoded, 60+ entries)
- Drill-to-string mapping is by category (rhythm→E, fretting→A, picking→D, etc.)

### Progress tracking:
- `localStorage['hearth-doing-progress']` — object keyed by drill ID
- Values: `true` (= mastered) or string: `'seen'`, `'practiced'`, `'clean'`, `'comfortable'`, `'mastered'`
- State display: colored dots on each drill card

### Filter system:
- Genre filters: Rock, Blues/Slide, Jazz/Gypsy, Metal, Classical, Country/Folk, Funk/Reggae, Latin/Flamenco
- Level filters: I through VIII
- Text search
- All rendered as pill buttons above the fretboard

### What's broken/missing:
- No drill completion triggers practice logging
- No integration with Practice node
- The drillLevels mapping is hardcoded (not from data)
- The fretboard doesn't respond to actual guitar tuning or key

### SVG icon:
- `assets/svg/icon-fretboard.svg` — 24×24 viewBox, gold (#d4af69) stroke
- Simple fretboard: rect outline, 6 horizontal string lines, 4 vertical fret lines, 2 position dots

## 3. KNOWING NODE — Bookshelf Library

### What it is
A scrolling bookshelf organized by 8 difficulty levels. Each level is a "shelf" with books (topics) displayed as cards. Uses a flipbook reader when you click a book.

### How it's built (showKnowing() in simulator.html ~line 2500)
Also generates HTML into `#p-foundation` (shared panel).

### Layout structure:
```
<div style="padding:20px;max-width:900px">
  <button class="back-btn">← Map</button>
  <div> <!-- header with icon + title -->
  </div>

  <!-- For each level (I-VIII): -->
  <div> <!-- level shelf -->
    <div> <!-- shelf header: Level I · Foundations · progress bar -->
    <div class="book-carousel" id="shelf-l1"> <!-- scrollable row -->
      <div class="book-card" onclick="openKnowingBook(catId, level)">
        <img class="book-cover" src="..."/>
        <div class="book-title">Rhythm</div>
        <div class="book-author">Author</div>
        <div class="book-progress">3/5 read</div>
      </div>
      ...
    </div>
  </div>
</div>
```

### Level structure (8 levels, each with color):
```javascript
const levels = [
  { level:1, label:'Level I',   sub:'Foundations',          color:'#c47a3a' },
  { level:2, label:'Level II',  sub:'Development',          color:'#4A6741' },
  { level:3, label:'Level III', sub:'Systems',              color:'#5B3A6B' },
  { level:4, label:'Level IV',  sub:'Navigation',           color:'#2C5F7C' },
  { level:5, label:'Level V',   sub:'Expansion',            color:'#8B6914' },
  { level:6, label:'Level VI',  sub:'Advanced Harmony',     color:'#6B3A3A' },
  { level:7, label:'Level VII', sub:'Modal Fluency',        color:'#3A5B6B' },
  { level:8, label:'Level VIII',sub:'Mastery',              color:'#6B5B3A' }
];
```

### Book card display:
- Each card shows: book cover image, title, author, progress (X/Y read)
- Cards grouped by category within each level shelf
- Scrollable horizontally per shelf (`book-carousel` class)

### Flipbook reader:
- Clicking a book calls `openKnowningBook(categoryId, level)`
- Opens a flipbook-style reader with page-flip animation
- Topics inside the book are displayed as pages
- Reading progress tracked per topic

### Progress tracking:
- `localStorage['hearth-knowing-progress']` — object keyed by topic ID (boolean = read)
- `localStorage['hearth-knowing-state']` — stores current `bookLevel` and read position
- Level unlocking: next level unlocks when 50% of previous level is read

### Data source:
- `window.KNOWING` object (loaded from `assets/js/knowing.js`)
- `KNOWING.categories[]` — each has `.id`, `.title`, `.topics[]`
- Each topic has: `id, title, body` (HTML), `source`, `difficulty`
- Book covers loaded from `images/knowing/<catId>-<level>.jpg`

### SVG icon:
- `assets/svg/icon-book.svg` — 24×24 viewBox, gold stroke
- Open book with left/right pages, spine line, text lines, bookmark ribbon

## 4. THE HEARTH — Brain Map (NOT DEPLOYED)

### What it is
A hand-drawn anatomical brain SVG with 9 guitar learning skill regions.
Each region is a glowing node connected by neural pathways to a central hub.
Clicking a region opens a detail panel with progress stats and navigation.

### Current status
- `assets/svg/brain-map.svg` — 11KB, exists in repo
- `assets/js/hearth-brain.js` — 350 lines, fully coded and functional
- `p-hearth` div exists in simulator.html (empty, populated by JS)
- **BUT**: `hearth-brain.js` is loaded at line 5354 but `showHearth` is overridden by scene-first.js
- **Result**: clicking Hearth on the map goes to scene-first version, not this brain version

### How it would work (hearth-brain.js):
1. `showHearth()` fetches `assets/svg/brain-map.svg` via fetch()
2. Injects SVG into `#p-hearth` with stats bar (streak, total time, notes count)
3. Makes skill node groups clickable via `attachSkillHandlers()`
4. Clicking a skill opens overlay panel with:
   - Skill name + color
   - Progress bar (calculated from localStorage data)
   - Description
   - Live stats (reads from DOING/KNOWING localStorage)
   - Guide text
   - Navigation buttons to relevant nodes

### 9 Skill Regions (positions in SVG):
| Skill | Color | SVG Position | Mapped Nodes |
|-------|-------|-------------|--------------|
| Ear Training | #8d5cff | (250, 170) | knowing, play |
| Technique | #4da3ff | (515, 200) | doing |
| Rhythm | #4da3ff | (602, 235) | doing |
| Theory | #8d5cff | (400, 380) | knowing |
| Improvisation | #2fffe6 | (465, 545) | play, create |
| Chords | #d9f45a | (1190, 420) | knowing, doing |
| Song Learning | #ff9d2e | (895, 560) | play |
| Performance | #ff654d | (605, 670) | mastery |
| Mastery | #8d5cff | (800, 795) | mastery |

### How stats are calculated (hearth-brain.js):
- **Ear Training**: counts knowing topics read / total topics
- **Technique**: counts doing drills mastered in picking/fretting/speed categories
- **Rhythm**: counts doing drills in rhythm category
- **Theory**: counts knowing topics read
- **Improvisation**: placeholder ("Start playing to unlock")
- **Chords**: counts knowing topics in chords category
- **Song Learning**: placeholder ("Explore the world map")
- **Performance**: counts practice log entries with feeling="nailed"
- **Mastery**: placeholder ("The journey continues")

### SVG anatomy:
- viewBox: `0 0 1600 950`
- Brain outline: anatomical brain path (frontal, parietal, occipital, temporal, cerebellum lobes)
- Brain is scaled 2.55× and translated to fit
- Sulci (brain folds): dashed animated lines
- Lobe labels: FRONTAL, PARIETAL, OCCIPITAL, TEMPORAL, CEREBELLUM
- Central hub: concentric circles with gradient fill + pulsing dot
- Pathways: colored bezier curves connecting each skill to the hub
  - `class="path developing"` — dashed, animated (not yet achieved)
  - `class="path active"` — solid, glowing (achieved)
- Tract labels: "Corticospinal tract", "Arcuate fasciculus", "Papez circuit"
- Each skill node: glow disc + icon circle + hand-drawn icon path + title + description
- All icons use the skill's color for strokes

### CSS animations in the SVG:
```css
@keyframes dashFlow { to { stroke-dashoffset:-120; } }
@keyframes pulse { 0%,100% { opacity:.62; transform:scale(1); } 50% { opacity:1; transform:scale(1.12); } }
```
- `.developing` paths animate dash flow
- `.glow-disc` and `.centre-dot` pulse

### Why it's not deployed:
- `scene-first.js` overrides `showHearth()` at load time
- The override function renders a different scene-first version
- To fix: either remove the scene-first override or rename the brain version

## 6. HOW NODE UI IS RENDERED

All 8 nodes render into the SAME panel: `#p-foundation`
Exception: Hearth renders into `#p-hearth`

```
<p class="pnl" id="p-map">        ← SVG map (always present)
<p class="pnl" id="p-foundation"> ← All node content renders here
<p class="pnl" id="p-hearth">     ← Brain map (empty div, populated by hearth-brain.js)
```

When you click a node:
1. `showNodeInfo(id)` → moves flame → calls `enterNodeAction(data)`
2. `enterNodeAction` dispatches to `showFoundation()`, `showDoing()`, etc.
3. That function clears `p-foundation`, generates HTML, sets `p-foundation.on`
4. Scene-first.js intercepts and may override this flow
