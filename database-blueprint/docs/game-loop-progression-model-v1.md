# Game Loop And Progression Model V1

## Purpose

The Hearth should not feel like a database of lessons.

It should feel like a learning world where progress is visible, earned, and alive.

The real gem is the game-like journey:

- levels
- goals
- accomplishments
- unlocks
- visible path
- meaningful practice
- personal growth

## Core Feeling

The learner should feel:

`I am becoming someone through repeated contact with this world.`

Not:

`I am checking off content.`

## Core Loop

The basic loop should be simple:

1. Enter the map.
2. See current quest or suggested next action.
3. Enter a node.
4. Do one meaningful action.
5. Receive feedback.
6. Earn visible progress.
7. Reflect briefly.
8. Return to the map with something changed.

This loop should work for:

- a 5-minute beginner action
- a 20-minute practice session
- a study session
- a creative prompt
- a full lesson

## Daily Loop

Recommended daily flow:

1. Open The Hearth.
2. See "Today's Path" or "Current Quest".
3. Choose:
   - continue current quest
   - do today's practice card
   - study a weak concept
   - create something
4. Complete one small action.
5. Log body/attention/reflection.
6. Earn progress, streak, or milestone.
7. See tomorrow's suggested return point.

## Weekly Loop

Recommended weekly flow:

1. Complete several small actions.
2. Watch one skill area move.
3. Complete one lesson or mini-quest.
4. Practice one repeating drill.
5. Save one reflection or creative seed.
6. See a weekly summary in Hearth.

The weekly summary should show:

- what was practised
- what improved
- what needs review
- what was created
- what source/concept was discovered
- what the next quest is

## Quest Types

### Main Quest

The main path through the current level.

Example:

`Level 1: First Contact`

### Node Quest

A focused quest inside one node.

Examples:

- Foundation: Complete the threshold
- Doing: Clean first picking drill
- Practice: Complete three body-aware sessions
- Study: Learn the first 10 terms
- Create: Complete one obstruction

### Daily Card

A small action for today.

Examples:

- Play one clean open string.
- Tap pulse for one minute.
- Read one source note.
- Try one creative prompt.
- Reflect on hand tension.

### Recovery Quest

A quest triggered by struggle.

Examples:

- Find the misunderstood word.
- Make the idea physical.
- Take the smaller step.
- Repeat the cleanest version.

Recovery quests should feel supportive, not punitive.

### Creative Quest

A challenge from Create.

Examples:

- Complete one obstruction.
- Save one song seed.
- Combine lyrics and rhythm.
- Return to a prompt after a practice session.

## Accomplishment Types

The app should recognize more than "complete / incomplete."

Recommended accomplishment types:

- lesson complete
- block complete
- node visited
- drill seen
- drill practised
- drill clean once
- drill comfortable
- drill mastered
- practice session complete
- streak held
- body reflection written
- misunderstood word resolved
- source note discovered
- book opened
- quiz passed
- creative prompt completed
- creative seed saved
- first chord attempted
- first clean sound made
- first song fragment saved
- level milestone reached
- node quest complete

## Progress States

Use progress states that feel like learning, not bureaucracy.

Suggested general states:

- unseen
- seen
- tried
- needs review
- clean once
- comfortable
- mastered

For reading/study:

- unread
- opened
- read
- reviewed
- needs review

For creative work:

- prompt drawn
- draft started
- seed saved
- returned to
- finished enough

For practice:

- planned
- started
- completed
- repeated
- reflected

## Level Model

Use plain Level 1 through Level 8 as stable database language.

Each level should have:

- theme
- main quest
- core skills
- recommended nodes
- required accomplishments
- optional accomplishments
- unlock condition
- Hearth reflection prompt

The level should feel like a chapter of becoming.

Not just:

`You finished 12 things.`

But:

`You can now use time feel, open chords, pentatonics, and first blues vocabulary in a small musical way.`

## Level 1 Feeling

Level 1 should feel like:

- beginning the QJam Level 1 technical path after Foundation
- improving time feel
- auditing and using the open-chord vocabulary
- changing between simple open chords
- learning pentatonic shape 1
- turning pentatonic notes into phrases
- entering first blues solo vocabulary
- connecting chords and scale phrases
- writing honest notes about ready, shaky, and missing skills

Level 1 is not about being advanced.

It is about making the first technical layer usable enough to support Level 2.

## Unlocks

Unlocks should be meaningful but not hostile.

Recommended unlock types:

- node introduction unlock
- lesson unlock
- practice card unlock
- source/library unlock
- creative prompt level unlock
- mastery inspiration unlock
- dashboard insight unlock

Unlocks should say:

`You are ready for this.`

Not:

`You are being kept out.`

## Rewards

Rewards should be subtle and soulful.

Avoid:

- casino-style points
- noisy badges
- fake urgency
- shame streaks

Use:

- map glow
- ring progress
- flame movement
- journal memory
- new guide line
- level milestone
- unlocked source
- completed quest card
- Hearth reflection summary

The reward should make the learner feel oriented, not manipulated.

## Hearth Dashboard Role

Hearth should answer:

- What is changing in me?
- What have I touched?
- What keeps returning?
- What wants review?
- What am I becoming able to do?
- Where should I go next?

Hearth is not just stats.

Hearth is the learner's memory chamber.

## Game Loop Across Nodes

### Foundation

Gives orientation and unlocks the first true path.

Progress feeling:

`I understand how this world works.`

### Doing

Turns skills into visible physical progress.

Progress feeling:

`My hands are becoming more capable.`

### Knowing

Turns references and concepts into trusted knowledge.

Progress feeling:

`I know where this idea comes from.`

### Practice

Turns repetition into ritual and memory.

Progress feeling:

`I returned, noticed, repeated, and improved.`

### Study

Turns confusion into understanding.

Progress feeling:

`The map in my mind is getting clearer.`

### Create

Turns skill into expression.

Progress feeling:

`I made something that did not exist before.`

### Hearth

Turns activity into identity and reflection.

Progress feeling:

`I can see myself changing.`

### Mastery

Turns the long path into inspiration.

Progress feeling:

`This goes somewhere vast.`

## Anti-Chore Rules

To keep the app from becoming chores:

- every task needs a visible purpose
- every drill needs a sound/music connection
- every theory idea needs mass
- every wrong answer needs re-explanation
- every stuck moment needs a recovery path
- every practice session needs a body/meaning reflection
- every level needs a felt milestone
- every accomplishment should feed the map or Hearth

## Database Implications

The backend should support:

- quests
- accomplishment types
- progress states
- unlock rules
- daily cards
- streaks
- reflections
- level milestones
- node recommendations

Suggested future tables:

- `quests`
- `quest_steps`
- `accomplishment_types`
- `student_accomplishments`
- `unlock_rules`
- `daily_cards`
- `student_reflections`

These do not all need to be built first.

But the content model should leave room for them.

## One-Sentence Summary

The Hearth should make learning feel like a quest where small honest actions become visible evidence of transformation.
