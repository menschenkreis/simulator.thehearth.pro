## Suggested Lesson Shape

### 1. Review And Body Scan

Time:

5 minutes

Ask:

- What did you notice in your hands this week?
- Did you try the riff?
- Did E and A string note locations make any sense yet?

Do:

- short shoulder, hand, jaw, breath scan
- one open-string sound check

Win condition:

Jen can notice one body thing before playing.

### 2. E And A String Root Map

Time:

10-15 minutes

Teach only the useful first layer:

- open E string
- open A string
- fret numbers as distance
- fret 12 as octave
- dots as landmarks
- E and A strings as root-note highways

Do not teach the whole fretboard.

Tiny task:

- find A on the low E string
- find C on the A string
- find E on the A string
- say the note name before playing it

Win condition:

Jen can find at least two root notes slowly without guessing wildly.

### 3. Pentatonic Shape As Vocabulary

Time:

10-15 minutes

Simple explanation:

The minor pentatonic is five notes that work well together. Treat it like a small vocabulary for speaking on guitar.

For now, do not over-explain modes or full scale theory.

Connect:

- A minor pentatonic starts around A
- the shape gives safe notes for call and response
- rhythm and repetition make it sound like music

Tiny task:

- play the shape slowly
- stop on A
- play only three notes and make a phrase

Win condition:

Jen can make a tiny phrase, not just run the scale.

### 4. Riff Check

Time:

15 minutes

Ask Jen to show the riff she wrote, even if incomplete.

If she did not write one:

- write one together using three pentatonic notes
- choose a rhythm
- repeat it twice
- change the ending

Coaching language:

- "A riff is a small musical idea that wants to be repeated."
- "Repetition makes it memorable."
- "Changing the last note makes it answer itself."

Win condition:

Jen leaves with one riff fragment she can repeat.

### 5. C Chord Gap Check

Time:

5-10 minutes

Only include this if the lesson is calm and not overloaded.

Purpose:

C chord showed up as a previous gap. Touch it lightly.

Do:

- show C chord shape
- name the hard finger
- connect it to "this is a future chord family doorway"

Do not demand mastery.

Win condition:

Jen can place fingers slowly or identify what makes it hard.

### 6. Reflection And Next Task

Time:

5 minutes

Ask:

- What sounded most like music today?
- What felt foggy?
- What should we repeat next time?

Assign:

- practise E and A string note locations
- keep one riff fragment alive
- play call and response with herself: question phrase, answer phrase

Log:

- body note
- fretboard note
- riff note
- confusion/gap
- next source Ayla needs to prepare
