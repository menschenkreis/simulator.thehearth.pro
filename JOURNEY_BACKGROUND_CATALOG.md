# Journey Background Catalog

This catalog tracks generated Journey background scene options.

Plain English: these are visual backgrounds only. The app should place guide characters, speech bubbles, and exactly 8 clickable level markers on top with code.

## Build Rule

- Do not bake final level markers into these images.
- Overlay exactly 8 app-controlled level buttons/hot-spots.
- Overlay the guide character from `assets/js/guide-character-data.js`.
- Keep any text, lesson status, and companion prep outside the background image.
