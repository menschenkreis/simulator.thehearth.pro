## How It's Organised
Each scale has:
1. **Title page** — numeric scale/mode chart, modal generation, keyboard fingerings, guitar fingering patterns
2. **Breakdown pages** — that scale in all 12 keys, complete fretboard patterns
3. Both conventional and sweeping patterns

## Maps to Simulator Sections
- **Reference Library → Scale Dictionary** — every scale in all 12 keys
- **Jazz Branch** — Bebop scales (Dominant, Dorian, Major, Locrian #2), Melodic Minor modes
- **Play → World Music** — Persian, Hungarian, Neapolitan, Pelog, Kumoi, Hirojoshi scales
- **Theory Library** — Building Blocks section, Chord Naming, Polychords, Compatibility
- **Knowing → Study** — Modal generation charts
