## Why This Is In The Knowledge Base

This resource is useful for the simulator as a teaching-pattern reference.

The useful idea is not to copy the handout. The useful idea is:

- Reduce the fretboard into small two-string blocks.
- Make the root note visually obvious.
- Repeat the same small idea in different places.
- Later, move the root note to change key.

## Current Use

For Jen's next lesson, use the gentle version:

- Stay in A minor.
- Treat A root notes as safety points.
- Break the pentatonic into three small boxes.
- Use 60 BPM first, then 76 BPM, then 100 BPM only if calm.
- Turn root notes into music before adding extra scale notes.

## Hearth Connection

This belongs partly in Hearth because it is about pattern recognition.
