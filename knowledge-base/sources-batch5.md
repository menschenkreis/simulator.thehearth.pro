## 25. Jazz Guitar — Mastering Chord Melody (Vol 3) — Jody Fisher
**Credit:** Jody Fisher, "Mastering Jazz Guitar: Chord Melody" (Alfred Publishing / National Guitar Workshop)
**Maps to:** Jazz Branch → Chord Melody, Play → Solo Guitar

### Table of Contents
- **Ch 1: Right-Hand Options** — Pick style, fingerstyle, pick + fingers (hybrid)
- **Ch 2: Melody + Harmony** — Recognizing chord tones, combining melody and harmony, guidelines for arranging, chord enhancement
- **Ch 3: Diads & Voice Leading** — Diads, non-chord tones, voice leading, passing chords, diminished/min7♭5 chords, quartal harmony, octaves
- **Ch 4: Passing Chord Approaches** — IV-I approach, V7-I approach, ii-V7-I approach, backcycling, tritone substitution, surprise chords
- **Ch 5: Walking Bass Lines** — Simultaneous chords + bass, scalewise approach, half-step approaches, rhythm, ii-V-I bass patterns
- **Ch 6: Moving Voices** — Moving voices, symmetrical chord movement, searching out new voicings
- **Coda:** Creating arrangements, listening to the greats

### Key value
- Complete guide to solo jazz guitar arrangement
- Teaches bass line + chords + melody simultaneously
- Passing chord approaches = the harmonic vocabulary for jazz

## 26. Jazz Guitar — Mastering Improvisation (Vol 4) — Jody Fisher
**Credit:** Jody Fisher, "Mastering Jazz Guitar: Improvisation" (Alfred Publishing / National Guitar Workshop)
**Maps to:** Jazz Branch → Improvisation (advanced)

### Table of Contents
- **Ch 1: Altered Dominant Chords** — Diminished scale, whole tone scale, Super Locrian (diminished whole tone), altered scale over ii-V-I, altered clusters, revamping licks

### Key value
- The advanced improvisation manual — altered scales, eight-tone scales, connection techniques

## 28. Fretboard Roadmaps — Fred Sokolow
**Credit:** Fred Sokolow, "Fretboard Roadmaps: The Essential Guitar Patterns" (Hal Leonard)
**Maps to:** Knowing → Fretboard Navigation, Reference Library

### The 12 Roadmaps
1. **Notes on the Fretboard** — tips for memorisation
2. **The Major Scale** — on one string (interval understanding)
3. **Two Moveable Major Chords** — barred E and A shapes
4. **The I-IV-V Chord Families** — blues and standard progressions
5. **The D-A-F Roadmap** — chord fragments through inversions
6. **Chord Fragment/Chord Families** — licks, strums, arpeggios from fragments
7. **The Circle of Fifths** — progressions across the entire fretboard
8. **Variations of Moveable Major Chords** — shortcut to all chord types
9. **Moveable Major Scales** — one per chord fragment
10. **Moveable Blues Scales** — three positions for licks and melodies
11. **Sliding Pentatonic Scales** — 5th and 6th string root
12. **Moveable Double-Note Lick** — Blues/Country/Rock/R&B

### Key value
- 12 roadmaps = 12 key patterns that unlock the entire fretboard
- Maps perfectly to our "mycelium" learning style — network thinking, not linear
- Each roadmap connects to the others — it's a relational system

## 29. The Ultimate Guitar Chord Chart — Phillip J. Facoline
**Credit:** Phillip J. Facoline, "The Ultimate Guitar Chord Chart II" (Hal Leonard)
**Maps to:** Reference Library → Chord Dictionary (comprehensive lookup)

### Structure
- Organised alphabetically by root note (Ab → A → Bb → B → C → Db → D → Eb → E → F → Gb → G)
- Within each root: major → minor → augmented → diminished → sus → add → extensions → alterations → slash chords
- Alternate voicings marked with periods (A7., A7.., A7...)
- Hundreds of chord fingerings
- Key reference table: diatonic chords in all 12 major keys
- Glossary of chord notation abbreviations

### Key value
- The comprehensive chord lookup table — "every chord you'll ever need"
- Reference tool, not a teaching method
- Perfect for the Reference Library section

## 30. Teach Yourself VISUALLY Guitar — Charles Kim (TOC from screenshots)
**Credit:** Charles Kim, "Teach Yourself VISUALLY Guitar" (Visual / Wiley, 2006)
**Maps to:** Foundation (visual learning approach)

### Full Table of Contents (from screenshots)
- **Ch 1: Introduction** — Versatility of guitar, hit the ground running, set goals (pp.4-6)
- **Ch 2: Parts of the Guitar** — Acoustic parts, electric parts, headstock, neck, body, bridge, string types, electric controls (pp.10-20)
- **Ch 3: Tuning** — Standard tuning, electronic tuner, relative tuning (pp.26-32)
- **Ch 4: Getting Into Position** — Sitting, standing, fretting hand, picking hand (pp.38-52)
- **Ch 5: First Chords** — How to read chord charts, D, A7, G (pp.56-61)
- **Ch 6: Moving Between Chords** — Economy of motion, common fingering, same fret, same string (pp.64-70)
- **Ch 7: Strumming & Picking** — Thumb strumming, pick playing, fingerpicking (pp.74-78)
- **Ch 8: Rhythm Guitar** — Tempo, 4/4 time, 4/4 patterns, 3/4 patterns (pp.82-87)
- **Ch 9: Rest of Open Chords** — A, B7, C, D, E, F, G chord families (pp.90-108)
- **Ch 10: Chord Symbols, TAB, Lead Sheets** — 5 chord types, reading TAB, playing from lead sheets, fingerpicking patterns (pp.112-125)
- **Ch 11: Suspensions & Bass Runs** — Suspension chords, bass runs in key of G (pp.132-152)
- **Ch 12: Capo & Barre Chords** — Capo use, barre technique, F chord, related barre chords, moving up/down neck (pp.156-168)
- **Ch 13: Chord Progressions** — Figuring out the key, Roman numerals, common progressions (pp.176-182)
- **Ch 14: Intro to Soloing** — Pentatonic scale, creating melodies (pp.186-191)
- **Ch 15: Advanced Techniques** — Slides, pull-offs, hammer-ons, vibrato, string bending (pp.196-208)
- **Ch 16: Purchasing & Maintenance** — Buying acoustic/electric/amp, string care, restringing, truss rod, intonation, humidification (pp.214-231)
- **Ch 17: Electric Guitar Sounds** — Guitar controls, amp controls, effect pedals (pp.234-238)
- **Ch 18: Continuing Education** — Private teacher, music theory, learning from others (pp.242-245)
- **Appendix A: Chord Charts** (p.246)
- **Appendix B: Scales** (p.252)
- **Appendix C: Guitar Gallery** (p.270)

### Key value
- Fully visual — colour photos for EVERY technique
- Perfect gradient: anatomy → tuning → position → first chords → moving → strumming → rhythm → all chords → reading → suspensions → barre → progressions → soloing → advanced → gear
- Maps to Hubbard's "mass" — visual = physical reality before abstraction
