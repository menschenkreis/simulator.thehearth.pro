## 41. Troy Nelson — Guitar Aerobics: 52-Week Workout
**Credit:** Troy Nelson, "Guitar Aerobics: A 52-Week, One-lick-per-day Workout Program" (2007, Hal Leonard)
**Status:** ✅ PDF downloaded (115 pages, 52MB) — text extractable ✅
**Maps to:** Practice → Daily Drills, Doing → Technique Development
**Key value:** PERFECT for the Practice node. 365 exercises, one per day, organized by:
- **Monday:** Alternate Picking
- **Tuesday:** String Skipping
- **Wednesday:** String Bending
- **Thursday:** Arpeggios
- **Friday:** Sweep Picking
- **Saturday:** Legato
- **Sunday:** Rhythm
Each week increases in difficulty. 6 styles: rock, blues, jazz, metal, country, funk. Includes CD tracks with metronome.

### Structure
- 52 weeks × 7 techniques = 364 exercises
- BPM range: 40-120+ with gradual increase
- Styles: Rock, Blues, Jazz, Metal, Country, Funk
- Graded difficulty: beginner → advanced over the year
