## 2. Introduction to Gypsy Jazz Guitar — John Jorgenson
**Credit:** John Jorgenson & Andy MacKenzie, "Swing Dreams Are Made of These: A Lesson in Gypsy Jazz" (Guitar Player, Dec 1996)
**Maps to:** Jazz Branch → Gypsy Jazz, Play → World Music
**Key content extracted:**

### Techniques
- **La Pompe rhythm** — percussive swing rhythm, accents on 2 & 4, precise muting
- **Rest-stroke picking** — pick follows through to rest on adjacent string. Core Gypsy Jazz technique
- **Arpeggio-based soloing** — chord shapes become melody tools
- **Sliding into notes** from half-step below, vibrato, rhythmic displacement

### Learning Progression (applies Hubbard gradient)
1. Rhythmic foundation — La Pompe on simple progressions (I-VI-II-V in G)
2. Harmonic language — arpeggios (Maj7, Min7, Dom7), Gypsy Major scale, Harmonic Minor
3. Technique integration — rest-stroke picking with metronome
4. Apply to a tune — Minor Swing, Djangology, Bossa Dorado
5. Melodic improvisation — arpeggios over changes, clean execution before speed
6. Advanced embellishment — slides, grace notes, rhythmic variations

### Theory
- Gypsy Major Scale (1, 2, b3, 4, 5, b6, 7)
- Harmonic Minor Scale
- Diminished 7th chords as passing chords
- Arpeggio theory — outline changes using 3rds and 7ths
- Chord substitutions

### Teaching approach (maps to our learning tech)
- Context-driven (history + spirit of Django first)
- Technique precision from the start (rest-stroke picking = non-negotiable)
- Ear and feel focused (listen to originals to internalise swing)
- Immediate practical application (theory → tune, fast)
- Step-by-step decomposition of complex concepts

## 4. Berklee Basic Guitar Phase 2 — William Leavitt
**Credit:** William Leavitt, "A Modern Method for Guitar — Phase 2" (Berklee Press)
**Maps to:** Doing → Drills, Knowing → Reading Music, Collab → Duets
**Key content extracted:**

### Techniques
- Sixteenth note rhythms (1-e-&-a counting)
- Alternate picking (down/up indicators)
- Position shifting
- Chord preparation (economy of motion)
- Polyphony (melody + accompaniment switching)

### Structure
- Standard notation ONLY (no TAB — forces reading)
- Chord grids above staff for left-hand shapes
- Left hand fingerings (1-2-3-4)
- Right hand picking directions
- Multi-staff duets (1st Guitar + 2nd Guitar)

### Duets
- "Maidens Wish" (Chopin)
- "Joy to the World" (Handel)
- Designed for class recitals

### Chord types
- Major, Minor, Dominant 7th, Diminished

### Berklee Method approach
- Reading-first (no TAB safety net)
- Rhythmic isolation (single string before cross-string)
- Counting syllables underneath staff
- Gradual complexity increase
- Ensemble playing from the start (duets)
