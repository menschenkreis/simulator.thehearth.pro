## 20. Guitar Patterns for Improvisation — William L. Fowler
**Credit:** William L. Fowler, "Guitar Patterns for Improvisation" (©1971, Maher Publications)
**Maps to:** Jazz Branch → Improvisation, Reference Library

### Table of Contents
| Ch | Title | Page |
|----|-------|------|
| I | Guitar Chord Fingering | 4 |
| II | Guitar Chord Studies | 9 |
| III | Transferral of Guitar Fingerboard Patterns | 12 |

| V-VIII | Guitar Fingerboard Scale Patterns (Parts 1-4) | 16-23 |
| IX | Three Useful Scales for Guitar Improvisations | 24 |
| X | The Whole-Tone-Half-Tone Scale and Its Use | 26 |
| | A Jazz/Blues Discography | 28 |

### Key concepts
- **Tetrachord system** — 4-note building blocks (Major, Minor, Phrygian, Diminished) combined into scales
- **19 types of seventh chords** derived by altering 3rd, 5th, 7th of major 7th
- **Pattern transferral** — move patterns across string sets, adjust 1 fret when crossing 2nd/3rd strings
- **Scale-to-chord mapping** — which scales work over which chords
- **Chromatic harmonic progressions**
- **Diminished scale** (whole-tone-half-tone) for jazz improvisation

## 21. Berklee Jazz Guitar Chord Dictionary — Rick Peckham
**Credit:** Rick Peckham, "Berklee Jazz Guitar Chord Dictionary" (©2007, Berklee Press / Hal Leonard)
**Maps to:** Reference Library → Chord Dictionary, Jazz Branch

### Part I: Chords
- **Moveable 7th Chord Shapes** — Major 7, Dominant 7, Minor 7, Min7♭5, Major 6, Minor 6, Diminished 7, Dom9, Min9, Min11, Dom13 (each on multiple string sets)
- **Dominant 7 Alterations** — 7♭5, 7(#11), 7♭9, 7#9, 7#5, 7(♭9♭13), altered (4 combos)
- **Guide Tone Chords** — Root-3-7 and Root-7-3 voicings for all 7th types
- **Triads over Bass Notes** — V/I, ♭VII/I, and other common voicings
- **Inversions** — Major 7, Dom 7, Min 7, Min7♭5, Maj6, Min6 (all string sets)

### Part II: Exercises
- Quartal voicings (C Dorian)
- Diatonic exercises (B♭ Major, E♭ Major, F Major)
- Harmonic Minor, Melodic Minor
- Bebop scales (Major 6 and Minor 6)

### Key value
- **100+ movable chord forms** with notation + fretboard diagram + TAB
- Reveals relationships between chord types (systematic, not random)
- The definitive jazz chord reference

## 22. A Modern Method for Guitar, Volume 1 — William Leavitt
**Credit:** William Leavitt, "A Modern Method for Guitar — Volume 1" (Berklee Press)
**Maps to:** Foundation, Doing → Drills, Knowing → Reading Music

### Learning Progression
1. **Reading notation** — no TAB, no shortcuts
2. **Time signatures** — top/bottom numbers, counting
3. **Note identification** — 1st position, upper register, ledger lines
4. **Dexterity development** — both hands, slow and steady
5. **Rhythm accompaniment** — bass notes + chords
6. **Chord symbols** — Major, Dom7, Minor
7. **Eighth notes** — counting and picking
8. **Original etudes** — musical compositions, not dry exercises
9. **Duets** — both parts for student practice

### Method philosophy
- Primary goal: READ MUSIC (no crutches)
- Secondary goal: dexterity in both hands
- Original compositions only (no "old favorites" that encourage playing from memory)
- Accumulative — every lesson builds, no skipping
- Slow, steady, constant review

## 23. Guitar Exercises For Dummies — Mark Phillips & Jon Chappell
**Credit:** Mark Phillips and Jon Chappell, "Guitar Exercises For Dummies" (Wiley)
**Maps to:** Doing → Drills (organised exercise library)

### Structure
- **Part I: Preparing to Practice** — Fundamentals review, warm-up routines
- **Part II: Scales & Sequences** — Major (5 patterns), 3 Minor scales (5 patterns each), scale sequences
- **Part III: Arpeggios & Sequences** — Major, Minor, 7th chord arpeggios, arpeggio sequences
- **Part IV: Chords & Single-Note** — Finger independence, strength/speed exercises
- **Part V: Tips** — 10 practice tips, 10 musicianship tips

### Exercise types
- 5-pattern scale system (CAGED-like)
- Scale sequences (melodic patterns within scales)
- Arpeggio patterns (major, minor, dominant, minor 7)
- Chord exercises for finger independence
- Single-note speed/strength drills
- Accompanying CD with play-along tracks
