# Generated Map Nodes v1 Alpha

Transparent, recentered versions of `images/map-nodes-generated-v1/`.

Why this folder exists:

- The first generated-v1 crops had baked-in dark square backgrounds.
- Those square backgrounds looked wrong inside the SVG map's circular node masks.
- This version removes the dark background, keeps the ivory/gold linework and glow, and recenters each icon by its visible artwork.

The simulator currently uses this folder for the main map node images.
