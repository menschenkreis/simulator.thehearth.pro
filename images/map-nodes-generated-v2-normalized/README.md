# Generated Map Nodes v2 Normalized

Transparent, normalized map-node assets derived from `images/map-nodes-generated-v1-alpha/`.

Why this version exists:

- The v1 alpha assets removed black square backgrounds, but the icons still felt uneven in the live map.
- Some icons were centered by faint glow or tiny sparkles rather than by the meaningful symbol.
- This version crops around the stronger artwork, reduces edge pressure, and rescales the icons with more breathing room.

The simulator currently uses this folder for the main map node images.

Fallback/reference folders:

- `images/map-nodes/`
- `images/map-nodes-clean/`
- `images/map-nodes-generated-v1/`
- `images/map-nodes-generated-v1-alpha/`
