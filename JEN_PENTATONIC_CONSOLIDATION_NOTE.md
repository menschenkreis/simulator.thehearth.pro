## Tomorrow's Lesson Shape

Theme: A minor pentatonic into music.

1. Tune in
   - Body scan, stretch, tune guitar, open-string sound.
   - Keep the mood calm and musical.

2. Root notes first
   - Find the A root notes inside the A minor pentatonic area.
   - Play only the roots with a metronome.
   - Make the root notes sound musical before adding more notes.

3. Tempo ladder
   - 60 BPM: main working speed.
   - 76 BPM: only if 60 feels calm.
   - 100 BPM: light test only, not a challenge or pass/fail moment.

4. Three small boxes
   - Break the pentatonic shape into three small areas.
   - Each box has its own root note as a safety point.
   - The student can return to the root whenever the map feels foggy.

5. Add nearby notes
   - Add one or two non-root notes from the pentatonic scale.
   - Make a tiny phrase.
   - Repeat it until it feels like music, not an exercise.

6. Musical conversation
   - One person holds A minor or a simple pulse.
   - The other answers with a tiny pentatonic phrase.
   - Swap roles.

7. Reflect
   - What root felt safest?
   - Which box felt clear?
   - Which tempo felt musical?
   - What should stay exactly the same for next practice?

What it shows:

- Reduce the fretboard into small two-string blocks.
- Highlight the root note clearly.
- Repeat the same small idea in several places.
- Later, move the root note to change key.
